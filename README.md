# 🏛️ Beacon Hill Academy - Admissions & Payments Portal

This high-fidelity application is a direct showcase proving that **ArtifactLoop is a powerful, continuous software engine** that goes far beyond a simple text-only chatbot.

## 🛠️ Complete Structural Features

1. **High-Fidelity Student Admission Register**: Validates and captures student registrations with complete relational structures.
2. **Dynamic Easypaisa Fee Calculator**: Allows customized, user-preferred PKR money amounts to build on-the-fly vector scan parameters.
3. **Transactional Sandbox Database Engine**: Ships with an automatic, localized sandbox mechanism inside local storage, but is fully pre-wired for **Supabase Cloud SQL Database** connection.
4. **Graphical Invoice canvas Renderer**: Click "Download Official Invoice" on any completed payment to programmatically draw a high-fidelity thermal receipt dynamically inside the browser and download as high-res PNG image.

---

## ⚡ Setup & Launch Instructions

### Running Locally
1. Since this is built modularly with canonical standards, you don't need complex server setups. Simply open `index.html` inside any browser.
2. By default, the application is in **Sandbox Mode** using your browser's virtualized storage so it runs instantly.

### Live Supabase Database Connection
1. Log into your **Supabase Console**.
2. Execute the commands found inside `supabase_schema.sql` inside the **SQL Editor** tab to instantiate tables, Row Level Security rules, and index pipelines.
3. Copy your project's **API Key (anon/public)** and **Project URL**.
4. In the upper right-hand corner of the Beacon Hill portal page, click **"Configure Supabase"** to save keys securely inside local sandbox. The system will immediately switch to live cloud sync mode.

## 💻 Technical Execution Architecture

- **Styling Core**: Tailwind CSS + Custom variable transitions.
- **Font System**: Clean typography using Google Inter and high-precision JetBrains Mono.
- **QR Engine**: External secure vector rendering interface.
- **Image Export**: HTML5 Canvas rendering context `2d` layout processing with structural margins and fonts.
